# Обновление portable-версии

Portable-сборка уже содержит Python и все библиотеки. Пользователю не нужно ставить Python или заново скачивать зависимости.

## Мягкое обновление

1. Закройте старую программу.
2. Распакуйте новую portable-сборку в отдельную временную папку.
3. Запустите из новой папки:

```cmd
update_portable.cmd "C:\Path\To\Old\SEOParser_Viki"
```

Скрипт обновит `.exe` и внутренние файлы приложения, но сохранит пользовательские файлы старой установки:

- `.env` с API-ключами;
- `parser.log`;
- существующую папку `data`, если она уже есть в старой установке.

Если нужно принудительно обновить bundled-справочники из новой сборки, используйте PowerShell-вариант:

```powershell
.\update_portable.ps1 -TargetPath "C:\Path\To\Old\SEOParser_Viki" -UpdateReferences
```

## Проверка версии

Номер версии отображается в заголовке окна и в нижней строке статуса. В portable-папке также есть файл `VERSION.txt`.
